# 🐍 Python GitHub Collab

A simple collaborative repository created to practice using GitHub as a team — covering branching, committing, pushing, and pull requests.

## 📚 Purpose

This repo is a learning exercise. The goal is to get comfortable with GitHub workflows by contributing to a shared Python project.

## 📁 Project Structure

```
.
└── main.py   # Main Python script
```

## 🚀 Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Run the script**
   ```bash
   python main.py
   ```

## 🤝 Contributing

1. Create a new branch for your changes
   ```bash
   git checkout -b your-branch-name
   ```

2. Make your changes to `main.py`

3. Commit and push
   ```bash
   git add .
   git commit -m "describe your change"
   git push origin your-branch-name
   ```

4. Open a **Pull Request** on GitHub and request a review
